How to read it: each dot is a unit — infantry small, tanks/vehicles mid, artillery ringed, epics large, structures square. Tracers are colored by damage type. Every type focus-fires the enemy it counters (lowest effective-HP), which is exactly why a mixed army beats a spam: it has an efficient answer to each threat while the spam pours all fire into one resisted target. The result and % value remaining match the headless sim exactly.
